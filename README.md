# 공지민 포트폴리오

밝은 흰색·분홍색을 중심으로 구성한 유아교사 개인 포트폴리오입니다.

## 구성

- 자기소개와 제공된 프로필 사진
- 숭의여자대학교 유아교육과: 2020.03–2023.02, 3년 과정, 4.16/4.5
- 사립유치원 담임교사: 2022.03–현재, 만 4년
- 직접 제작한 소식지 4편의 첫 페이지와 전체 소식지 18편 PDF

`docs/index.html`을 브라우저에서 열면 볼 수 있습니다. 별도 빌드 없이 `docs` 폴더를 정적 웹사이트로 호스팅할 수 있습니다.

본문은 `docs/index.html`, 디자인은 `docs/styles.css`, PDF는 `docs/pdfs`에 있습니다.

## 사용한 자료

- 프로필: `0/KakaoTalk_20260521_082915670.jpg`
- 소식지: `6-1.pdf`, `7-2.pdf`, `8-4.pdf`, `9-4.pdf`의 첫 PDF 페이지를 이미지로 변환
- 원본 문서는 수정하지 않았으며 전체 PDF 23개가 포함되어 있습니다.
- 자기소개 및 작품 설명은 제공된 경력과 소식지 내용을 바탕으로 작성한 초안입니다.

월안 4편은 2페이지를 썸네일로 사용하며, PDF 링크는 2페이지에서 열립니다.
활동내용은 11페이지를 썸네일로 사용하며 전체 16페이지 PDF를 열 수 있습니다.
모든 PDF 링크는 새 탭에서 열립니다.
